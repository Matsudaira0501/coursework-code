# 授業・演習で作成したプログラム集

大学での授業・演習・個人学習で作成したコードを、言語とテーマ別にまとめたリポジトリです。**ゲーム処理、コンパイラ、ネットワーク、機械学習など、基礎的な実装経験**を確認できます。

> このリポジトリは学習時のコードを保管したアーカイブです。各ファイルは独立した課題・実験に対応しており、全体を一括でビルド／実行するプロジェクトではありません。

## 主なコードへのリンク

| 分野 | 内容 | コード |

## 実行する際の注意

- 実行環境や必要なライブラリはファイルごとに異なります。
- 例えば、一部のC++コードは `ncurses`、Pythonの構文解析コードは `PLY` を利用します。
- 課題で指定された入出力ファイルや環境に依存するものがあります。利用する際は各ソースの内容を確認してください。
- 学習過程のコードのため、未完成部分や改善余地が残っている可能性があります。

## 公開・利用について

授業用テンプレートやサンプルを基にした可能性のあるコードが含まれます。再利用する場合は各授業・原著作者の条件を確認してください。**第三者のコードに対するライセンスを付与するものではありません。**

課題文、講義資料、提出文書、個人情報、実行ファイル、画像は含めていません。
