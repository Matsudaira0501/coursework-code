# Coursework Code Archive

授業、演習、個人学習で作成したプログラムコードのアーカイブです。

## Structure

- `c/`: C言語
- `cpp/`: C++
- `python/`: Python
- `notebooks/`: Jupyter Notebook
- `shell/`: シェルスクリプト
- `projects/`: 複数ファイル構成の課題

## Important notice

授業用テンプレートやサンプルを基にした可能性のあるコードが含まれます。再利用時は各授業・原著作者の規約を確認してください。このリポジトリから第三者コードへのライセンスは付与しません。

課題文、講義資料、提出文書、個人情報、実行ファイル、画像は含めていません。
